# Participant-diagram learning design

The subject is ontology meaning and library operations. Incident data is illustrative context. Six UML-like sequence diagrams use 3–4 named participants, lifelines, ordered requests/replies and self-calls. A pure lesson model owns semantics and Mermaid exports; SVG owns stable geometry and message selection.

One diagram is rendered at a time. A compact inspector connects each message to an actual definition, operation, source or native result. Controls step through messages, show all, fit/reset and switch lessons. Public/local vocabulary provenance and conceptual/recorded operations are explicit.

Mobile preserves participant columns on a horizontally scrollable intrinsic canvas. Text does not automatically shrink. An optional Fit toggle shows the whole diagram. Page vertical scroll remains available. Full rows support tapping and keyboard activation. Reduced motion is honored.

QA covers participant/message order, exports, native vocabulary/SHACL/query/inference/plan outputs, proposal variants, reasoning replay, URL restoration, sources, desktop/mobile layout and the public deployment. No model key, user credentials, tracking or incident execution is involved.
